# [백준] 1000 A+B (C++/입출력)

## 문제 요약
두 정수를 입력받아서 합을 출력하는 문제다.
처음 풀어 보기 좋은 입출력 연습 문제 같다.
문제 링크: [https://www.acmicpc.net/problem/1000](https://www.acmicpc.net/problem/1000)

## 난이도 / 알고리즘 태그
- 난이도: 입문 (solved.ac 난이도는 확인하지 못했다)
- 태그: 입출력, 사칙연산 (직접 분류한 것으로 확인 필요)

## 접근 방법
계산 자체는 덧셈 한 번이라 크게 고민할 건 없었다.
오히려 알고리즘보다 C 언어의 기본 사용법이 문제였다.
오랜만에 C 언어를 쓰려고 하니까 `#include <stdio.h>`, `%d`, `&a` 같은 기본 호출 방법이 조금 헷갈렸던 것 같다.

처음 쓴 코드에는 문제가 두 가지 있었다.
- 헤더 이름을 `cstudio.h`로 잘못 적어서 컴파일이 안 됐다.
- `scanf("%d\n", &a)`처럼 형식에 `\n`을 넣었는데, 입력이 더 들어오길 기다리며 멈출 수 있는 방식이었다.

그래서 헤더를 `<stdio.h>`로 고치고, 숫자 두 개를 `scanf("%d%d", &a, &b)` 한 번에 읽도록 바꿨다.
예제랑 입력 범위 끝값으로 직접 실행해 보니 결과가 맞게 나왔다.

## 사용한 개념 정리
입력과 출력은 프로그램이 바깥이랑 데이터를 주고받는 통로이다.
채점기는 입력을 넣고, 나온 출력이 정답과 같은지만 본다.
그래서 안내 문구 같은 여분의 글자를 같이 출력하면 틀린 답이 된다.

헷갈렸던 세 가지를 정리해 봤다.
- `#include <stdio.h>`: 입출력 도구(`scanf`, `printf`)를 가져다 쓰겠다는 선언이다. C++에서는 `<cstdio>`로도 쓸 수 있다.
- `%d`: 정수 하나를 읽거나 출력하겠다는 뜻의 서식 문자이다.
- `&a`: 읽은 값을 변수 a라는 상자에 넣어 달라고 변수의 위치를 알려 주는 것이다. `scanf`에서만 붙이고 `printf`에서는 붙이지 않는다.

`scanf`의 형식 안에 `\n`이나 공백을 쓰면 "공백을 전부 건너뛰고 다음 글자를 기다린다"는 뜻이 된다.
그래서 숫자를 읽을 때는 `\n`을 빼는 게 안전한 것 같다.

## 풀이 코드
```cpp
#include <stdio.h>
int main(){
    int a, b;
    scanf("%d%d", &a, &b);  // 한 줄의 정수 두 개를 한 번에 읽는다
    printf("%d", a+b);      // 합만 출력한다
}
```

## 시간복잡도 / 공간복잡도
- 시간복잡도: O(1). 입력 읽기, 덧셈, 출력이 각각 한 번씩이라 입력이 커져도 계산량이 늘지 않는다.
- 공간복잡도: O(1). 정수 변수 두 개만 쓴다.

`scanf`에 `\n`을 넣는 습관은 고쳐야 할 것 같다.
