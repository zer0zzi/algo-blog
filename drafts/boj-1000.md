# [백준] 1000 A+B (C++/입출력)

## 문제 요약
두 정수를 입력받아 합을 출력하는 문제다.
백준에서 가장 먼저 풀어 보는 입출력 연습 문제이다.
문제 링크: [https://www.acmicpc.net/problem/1000](https://www.acmicpc.net/problem/1000)

## 난이도 / 알고리즘 태그
- 난이도: 입문 (solved.ac 난이도는 확인하지 못했다)
- 태그: 입출력, 사칙연산 (직접 분류한 것으로 확인 필요)

## 접근 방법
계산 자체는 덧셈 한 번이라 고민할 것이 없었다.
막힌 곳은 알고리즘이 아니라 C 언어의 기본 사용법이었다.
오랜만에 C 스타일로 쓰려니 `#include <stdio.h>`, `%d`, `&a`를 어떻게 쓰는지가 헷갈렸다.

처음 쓴 코드에는 두 가지 문제가 있었다.
- 헤더 이름을 `cstudio.h`로 잘못 적어서 컴파일 자체가 되지 않았다.
- `scanf("%d\n", &a)`처럼 형식에 `\n`을 넣었다. 입력이 더 들어오길 기다리며 멈출 수 있는 습관이었다.

해결은 두 가지였다.
헤더를 `<stdio.h>`로 고쳤고, 숫자 두 개를 `scanf("%d%d", &a, &b)` 한 번으로 읽었다.
고친 코드로 예제와 입력 범위 끝값을 직접 실행해서 맞게 나오는 것을 확인했다.

## 사용한 개념 정리
입력과 출력은 프로그램이 바깥과 데이터를 주고받는 통로이다.
채점기는 입력을 넣고, 나온 출력이 정답과 같은지만 본다.
그래서 안내 문구 같은 여분의 글자를 출력하면 틀린 답이 된다.

C 스타일 입출력에서 헷갈렸던 세 가지를 정리했다.
- `#include <stdio.h>`: 입출력 도구(`scanf`, `printf`)를 가져다 쓰겠다는 선언이다. C++에서는 `<cstdio>`로도 쓸 수 있다.
- `%d`: 정수 하나를 읽거나 출력하겠다는 서식 문자이다.
- `&a`: 읽은 값을 변수 a라는 상자에 넣어 달라고 변수의 위치를 알려 주는 것이다. `scanf`에서만 붙이고 `printf`에서는 붙이지 않는다.

`scanf`의 형식 안에 `\n`이나 공백을 쓰면 "공백을 모두 건너뛰고 다음 글자를 기다린다"는 뜻이 된다.
숫자를 읽을 때는 `\n`을 쓰지 않는 편이 안전하다.

## 풀이 코드
```cpp
#include <stdio.h>
int main(){
    int a, b;
    scanf("%d%d", &a, &b);  // 한 줄의 정수 두 개를 한 번에 읽는다
    printf("%d", a+b);      // 합만 출력한다
}
```

## 시간복잡도 / 공간복잡도
- 시간복잡도: O(1). 입력 읽기, 덧셈, 출력이 각각 한 번씩이라 입력이 커져도 계산량이 늘지 않는다.
- 공간복잡도: O(1). 정수 변수 두 개만 쓴다.

`scanf`의 형식 문자열에 `\n`을 넣는 습관은 고쳐야겠다.
